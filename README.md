# Machine Learning Experiments (Python)

## 專案簡介
本 Repo 整理大學後期機器學習課程之實作內容，涵蓋資料前處理、模型訓練、效能評估與結果分析。  
重點在於建立可重現的 ML pipeline，並透過不同模型/參數設定的比較來理解模型表現差異。

## 使用技術
- Language: Python  
- Libraries: numpy, pandas, scikit-learn, matplotlib  
- Tools: Jupyter Notebook, Git  

## Repo 結構
- `notebooks/`：課程作業與實作（主要展示）
- `KaggleComp/`：Kaggle 相關專案（資料處理、特徵工程、建模與提交流程）

## 建議閱讀順序
1. [`ML_Pipeline_HW11_3.ipynb`](notebooks/ML_Pipeline_HW11_3.ipynb)  
   - 主打：完整機器學習流程（資料處理 → 訓練 → 評估），展示 pipeline 與實作能力

2. [`Model_Comparison_HW12_4.ipynb`](notebooks/Model_Comparison_HW12_4.ipynb)  
   - 加分：不同模型/參數設定的比較與分析，展示實驗設計與結果解讀能力
