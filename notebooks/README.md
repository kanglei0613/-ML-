# Machine Learning Experiments (Python)

## 專案簡介
本專案整理大學期間機器學習課程之實作內容，
涵蓋資料前處理、模型訓練、效能評估與結果分析，
重點在於完整的機器學習流程實作。

## 使用技術
- Language: Python
- Libraries: numpy, pandas, scikit-learn, matplotlib
- Tools: Jupyter Notebook, Git

## 實作內容
- 監督式學習（Regression / Classification）
- 特徵處理與資料前處理
- 模型訓練與效能評估
- 不同模型與參數設定比較

## 建議閱讀順序
1. `notebooks/classification_XXX.ipynb`  
   - 分類問題的完整流程（資料處理 → 訓練 → 評估）

2. `notebooks/model_comparison_XXX.ipynb`  
   - 不同模型或參數設定的比較與分析

## 備註
此專案為課程實作，著重於流程理解與實驗設計。
